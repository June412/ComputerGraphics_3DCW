# Reality Link: Cyber Travel

**CPT205 — Computer Graphics**

An interactive 3D journey from a futuristic room to a cyberpunk city, built with C++ and OpenGL. Explore animated traffic, changing lighting, and rain.

[Project report](report.pdf) · [Source code](cyber_travel.cpp)

## Run

On Windows, run from the project folder:

```powershell
cd textures
..\test.exe
```

Keep `textures` as the working directory for the included executable. Click **Start**, then press **Space** to enter the city. Move the mouse to look around; use **W/S** to move, **1/2/3** to change lighting, **R** for rain, and **Esc** to quit.
